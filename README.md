# React Match Game

A memory-style matching game built with React.

> **Status:** early prototype. The board and score display are in place, but the score is a placeholder value and the matching logic is not finished.

## Setup

Requires Node.js.

```sh
yarn install
yarn start
```

The app runs at http://localhost:3000.

## Scripts

- `yarn start`: development server
- `yarn build`: production build
- `yarn test`: run tests

Created with Create React App (`react-scripts` 1.0.17) and React 16.
